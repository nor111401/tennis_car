# Tennis Rover 控制终端

这是网球小车的 Windows/安卓共享控制终端第一版。它采用浏览器原生 WebSocket 控制和
认证JPEG视频，不把自动追球算法放在客户端；树莓派始终是车辆状态和运动控制的唯一权威。

## 当前具备

- 可安装的响应式 PWA 图形界面。
- 浅色蓝绿控制台：桌面宽度超过900px且高度不低于约600px时，视频、模式、驾驶、急停及
  状态卡片采用一屏布局；视频区域按窗口高度自适应，日志在卡片内滚动。手机和更小窗口
  保留正常页面滚动，避免隐藏控制按钮。样式覆盖位于 `console-light.css`，PWA缓存为v13。
  视频显示框为1:1方形，按可用宽高缩放，与网关正方形裁剪画面匹配；保持完整显示，
  不拉伸或二次裁切，桌面同时收窄视频卡片以减少两侧空白。
  视频占位层收到首帧后通过明确的 `[hidden]` 样式隐藏，避免浅色背景遮住实时图像。
- 自动、手动、暂停三种模式入口。
- 控制权申请和释放界面。
- 按住移动、松开停车的方向控制，支持 W/A/S/D 和触摸。
- 手动速度调节、250ms 控制心跳和独立紧急停车入口；默认100%，前进、后退和左右转向在
  滑块满量程时都使用协议最大PWM 2500/500。
- 视频区域、识别框、置信度、FPS、延迟、电机及串口状态显示。
- 待确认主球在视频中显示黄点，确认主球显示红点和网页绿框，其他球蓝点。
  搜索中出现有效主候选时先停车`TARGET VERIFY`最多1秒，停稳后新确认帧才追踪，
  超时继续搜索；重复候选不续期，持续未确认候选不会反复锁住车辆。识别门槛不变。
- 追踪/捡球模式按钮：在手动/暂停模式下取得控制权后可切换 BCM17 低/高电平；自动
  模式由树莓派自行控制：确认可见球框下沿≥0.80、近区中心±0.15内允许前进即启动，
  车辆固定直行和收集高电平同时持续3秒，可从近处起步，不再等球消失。
  期间目标重现/消失/拒绝/偏移/视觉过近不取消、不续期；暂停/急停/相机异常/UART故障等仍停车。
  到时停车、收集输出低；同一仍在近区的球显示`PICKUP COMPLETE`且不重复触发。
- 下沿≥0.80时方向容差放宽到±0.15，小偏差继续直行；远区仍±0.06，大偏差仍小步对准。
- 原`PICKUP PARTIAL WAIT`裁切等待已移除；收集期间不再受半球识别结果影响。
  入口前仍须确认识别及面积/新帧检查；本次开机临时启用超声，近障碍可提前取消3秒收集。
  整机重启恢复超声关闭/PAUSED；只能在空旷有人看护的场地操作。
- 认证 JPEG 视频客户端和 WebSocket 实时控制协议客户端。

## 本地运行

要求 Node.js 18 或更高版本，不需要安装第三方 npm 包。

```powershell
cd D:\liugensheng\tennis\control_terminal
npm test
npm start
```

如果 PowerShell 的执行策略阻止 `npm.ps1`，直接使用 `npm.cmd test` 和 `npm.cmd start`，
不需要修改系统执行策略。

然后在 Edge 打开 `http://127.0.0.1:4173`，填写树莓派地址和访问令牌并连接小车。通过
Edge 菜单中的“应用 → 将此站点作为应用安装”，可以获得独立的 Windows 应用窗口和
开始菜单入口。

## 真实小车连接状态

树莓派认证网关可以建立真实控制、状态和视频通道。摄像头、现有网球识别模型、目标遥测
和 JPEG 实时画面均已接入；视频使用单槽最新帧缓冲，网络或解码较慢时不会堆积旧画面。

`MotorController` 已处于统一模式仲裁之后，当前树莓派部署设置 `TENNIS_MOTOR_ENABLE=1`。
取得控制权并进入 MANUAL 后，方向按键会实际驱动车辆；树莓派重启后从 `AUTO` 开始追球。
手动模式支持前进、后退、左转和右转；后退可使用 `S`、向下方向键或界面下箭头。

当前默认地址为 `ws://10.183.95.9:8765/ws`，对应现场树莓派地址。终端会自动迁移此前
保存的 `ws://192.168.0.108:8765/ws`，但保留用户填写的其他地址。树莓派使用 DHCP，地址变化后
仍需在页面地址栏更新为当前地址。

树莓派常驻服务要求访问令牌。令牌只保存在树莓派 root 权限文件中，终端需要把同一个
令牌填入“访问令牌”输入框；不带令牌的连接会被服务端拒绝。

追踪/捡球模式与 AUTO/MANUAL/PAUSED 驾驶模式相互独立。树莓派服务默认输出追踪模式低电平，
捡球模式输出高电平；该信号脚为 BCM17（物理排针 11），UART 使用 BCM14/15（物理排针
8/10）。外接控制器需要与树莓派共地并兼容 3.3V GPIO。

## 安全约束

- 打开终端只获得只读观看能力，不自动接管小车。
- 只有取得控制权且进入 MANUAL 后，方向输入才有效。
- 指针、按键、窗口焦点或页面可见性丢失时，客户端立即发送 STOP。
- 客户端每 250ms 发送心跳；服务端独立实现 600ms 的失联停车看门狗。
- 客户端断线后服务端不得自动恢复 AUTO，必须停在 MANUAL_LOST 等待确认。
- 紧急停车由服务端锁存，客户端只能申请解除，服务端仍需执行权限与状态校验。

完整协议和树莓派接入边界见 `../docs/CONTROL_TERMINAL_ARCHITECTURE.md`。
